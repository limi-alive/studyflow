# StudyFlow CLEAN v14.0.1 — شروع از نسخه یکپارچه

این نسخه از سورس واقعی آرشیو ارسالی (`main` در Commit `c8ebf27`) ساخته شد؛ **دو آپدیت v13.8 و v14 به‌شکل انتخابی ادغام شده‌اند**. کپی کورکورانه پچ‌ها انجام نشده است.

## فقط این مراحل

1. برای حفظ داده‌ها و تاریخچه Git، پوشه فعلی StudyFlow را **حذف نکن**. نام آن را به `studyflow_BACKUP` تغییر بده یا یک کپی امن از آن نگه دار.
2. این ZIP را در یک پوشه جدید استخراج کن (مثلاً `StudyFlow_CLEAN_v14_0_1`). فایل `.git`، `.env`، اطلاعات Supabase و `node_modules` داخل ZIP نیستند.
3. روی **`STUDYFLOW_START.cmd`** دابل‌کلیک کن. این فایل `npm ci`، Lint، TypeScript، تست‌ها، تست تاریخ شمسی و Build را به‌ترتیب اجرا می‌کند.
4. وقتی همه بررسی‌ها موفق شدند، برای Push شاخه بررسی، کلمه `YES` را تایپ کن. اگر نمی‌خواهی منتشر کنی Enter بزن. ابزار از GitHub یک clone تازه می‌سازد و با اجازه تو **فقط شاخه جدید** را Push می‌کند؛ `main` و پوشه قبلی‌ات دست نمی‌خورند.
5. لینک Pull Request چاپ‌شده را باز کن. بعد از سبز شدن GitHub Actions و بررسی Diff، PR را Merge کن. بعد روی گوشی اپ را کامل ببند و دوباره باز کن.

**توجه:** این بسته به Commit `c8ebf27` متکی است. اگر GitHub `main` بعد از آن تغییر کرده باشد، ابزار به‌جای بازنویسی، متوقف می‌شود تا نسخه سازگار آماده شود.

## چه چیزهایی اضافه/اصلاح شده‌اند؟

- StudyOS: برنامه روز، رادار امتحان، مرور فعال و تحلیل مطالعه.
- تاریخ‌های نمایشی شمسی، تاریخ‌گزین شمسی برای تکالیف، امتحان‌ها و ثبت دستی Session.
- صفحه مستقل «پیشرفت» برای چالش ۷روزه و کارت اشتراک‌گذاری. این‌ها دیگر وسط داشبورد نیستند.
- حفظ منطق لیدربورد ماهانه، حساب‌کردن جایزه ۲۸ساعته و Sync تنظیمات در نسخه اصلی.
- ساختار پوشه تمیز: بدون `StudyFlow_Updates`، `node_modules`، `.git`، `dist`، فایل‌های موقت و نصاب‌های قدیمی.

## امنیت و محدودیت‌ها

این بسته هیچ SQL جدیدی اجرا نمی‌کند، به دیتابیس تولید دسترسی ندارد و سابقه کاربران را پاک نمی‌کند. فایل `.env` و اطلاعات محرمانه را **هرگز** در ZIP قرار نده.

تاریخ‌های دیتابیس همچنان ISO می‌مانند. دوره‌های حسابداری قدیمی جایزه ممکن است بر اساس تقویم میلادی باقی مانده باشند، اما بازه واقعی با تاریخ شمسی نمایش داده می‌شود. تغییر گذشته مالی به مهاجرت و تأیید جداگانه نیاز دارد.

مرور فعال هنوز سیستم حرفه‌ای فلش‌کارت فاصله‌دار نیست. چالش دوستان نیز رقابت زنده با ثبت پیشرفت مشترک نیست.

## عیب‌یابی

اگر `npm ci` یا تستی خطا بدهد، هیچ Push انجام نمی‌شود. خروجی همان پنجره را بفرست. اگر GitHub جلوتر رفته باشد، ابزار تغییرات را روی نسخه دیگری به زور اعمال نخواهد کرد.
