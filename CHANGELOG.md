# Changelog

## 0.1.0
### Added
- Mobile-first React/TypeScript PWA shell.
- Timestamp-based persistent stopwatch/countdown/Pomodoro foundation.
- IndexedDB offline persistence with UUID records.
- Subjects, tasks/planner, manual sessions, history, statistics, profile and settings.
- Twelve initial visual themes, RTL switch and Persian/English preference foundation.
- Supabase authentication, schema, RLS policies and two-way sync foundation.
- JSON backup export and PWA service worker.
- CI checks and GitHub Pages deployment workflow.

## 0.3.0 - Visual polish & expressive themes
- Rebuilt desktop and mobile navigation as a floating glass layer with smoother route transitions.
- Added a modern bento-style Home dashboard with richer hierarchy, progress orb, refined metrics and animated weekly bars.
- Redesigned Timer as a focus studio with expressive mode cards, improved Mochi scene, ambient depth and cleaner controls.
- Rebuilt Settings into a visual theme studio with live theme previews and four new themes: Jelly Pop, Matcha Milk, Lavender Mist and Ocean Glass.
- Added Command/Ctrl+K quick actions, stronger focus states, responsive spacing, improved corner geometry and reduced-motion support.
